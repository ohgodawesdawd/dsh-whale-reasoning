# Artwork and attribution

The included whale-girl illustrations were AI-generated for the project and
provided by the project contributor for distribution with this open-source plugin.
No photographs, private portraits or third-party theme screenshots are included.

## Included states

| State | Illustration |
| --- | --- |
| minimal | Empty worn bowl, pleading expression |
| low | A few grains, hungry expression |
| medium | A small serving, drooling |
| high | Full rice bowl, happy expression |
| xhigh | Rice mountain, star eyes, short arms naturally holding the bowl |
| max | Large rice pot, ecstatic expression, legs hidden behind pot |
| auto | Automatic-choice illustration |
| off | Rest/off illustration |

Masters are 1024×1024 RGBA; runtime images are 672×672. The common sole baseline
is approximately y=942 in the master canvas. Export/source SHA-256 values are in
asset-manifest.json. xhigh was replaced by an approved generated correction on
2026-11-06; all other seven sources remained unchanged in version 1.2.1.
